# Cell Clustering Plugin [![Actions Status](https://github.com/ManiVaultStudio/CellClusteringPlugin/actions/workflows/build.yml/badge.svg?branch=main)](https://github.com/ManiVaultStudio/CellClusteringPlugin/actions)

Cell clustering plugin for the [ManiVault](https://github.com/ManiVaultStudio/core) visual analytics framework based on the [alxvth/CellClustering](https://github.com/alxvth/CellClustering) library. 
Currently, only one cell clustering algorithm is implemented (PhenoGraph).

## References
- PhenoGraph ([Levine et al., Cell 2015](https://doi.org/10.1016/j.cell.2015.05.047))
